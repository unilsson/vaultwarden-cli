# Changelog

## 2.2.0 — 2026-10-12

- Initial GitHub release of `vw`.
- Detailed and minimalist fzf interfaces (`vw --simple`, `Ctrl+V`).
- Copy passwords, usernames and TOTP through rbw clipboard integration.
- Folder filtering, fuzzy search over entry metadata and alphabetical sort.
- Open websites in Firefox or the system browser.
- Sync the vault without leaving the interface.
- Installation/uninstallation scripts and ShellCheck CI.
